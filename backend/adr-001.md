# ADR-001: Database Selection for Project Alpha

## Decision
We selected PostgreSQL as the primary database for Project Alpha.

## Reasoning
Project Alpha's data is highly relational — users, orders, and inventory —
and benefits from PostgreSQL's transactional guarantees. The pgvector
extension also lets us handle semantic search in the same database,
avoiding a second specialized system. The team already has strong
PostgreSQL experience, reducing onboarding time.

## Approval
Approved by Sarah Chen, Engineering Manager, after architecture review.
